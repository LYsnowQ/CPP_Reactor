## 2. Historical license (not revocable)

The following were released under **MIT**:

- all commits through `be3bc0b` (inclusive);
- tags `v1.0.0`, `v1.1.0`, and `v1.2.0`.

PolyForm Noncommercial applies from `v2.0.0` onward. It does not retroactively change the MIT
versions above. The MIT text is preserved in [LICENSE-MIT](./LICENSE-MIT).

**Changing the license does not revoke rights already granted under MIT.** Anyone who obtained
a copy while MIT applied may continue to use it under MIT, including commercially. As a result:

- new code from this repository is under PolyForm Noncommercial;
- earlier code (for example commit `429dcaf`, the fix selected by XERJ) remains usable under MIT;
- if you want an earlier inclusion removed, ask the indexing party directly; a license change
  cannot retroactively undo it.
