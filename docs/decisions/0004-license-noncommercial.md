# 0004 — 改为非商业许可（历史 MIT 保留）

- 状态：accepted
- 日期：2026-11-06
- 相关：[LICENSING.md](../legal/LICENSING.md)、[LICENSE](../../LICENSE)、
  [LICENSES/MIT.txt](../../LICENSES/MIT.txt)、
  issue [#5](https://github.com/LYsnowQ/CPP_Reactor/issues/5)

## 背景

项目长期以 MIT 发布，定位是个人 C++ 学习项目。2026-11-06 收到第三方代码语料库
（XERJ Corpus Hub）的收录通知，拟将 commit `429dcaf` 以 MIT 收录，用于给 coding agent
提供“参考实现”。

这暴露了一个此前没有明确回答的问题：项目是否允许被商业产品直接使用、索引或用于
商业性 AI 语料？所有者的意图是：

- 不希望商业产品直接使用或收录；
- 但允许通过商业渠道**免费**分享（不收费、不捆绑付费产品）；
- 不希望把已经公开的 MIT 授权说成可以“撤回”。

## 决策

1. 从本决策所在提交起，新代码采用 **PolyForm Noncommercial License 1.0.0**；
2. 增加**免费再分发**的附加许可（任意渠道，含商业平台，不得收费/捆绑付费产品）；
3. 历史代码（截至 `be3bc0b`，含 tag `v1.0.0`–`v1.2.0`）继续适用 MIT，原文保留为
   `LICENSES/MIT.txt`；
4. 在 `docs/legal/LICENSING.md` 中明确“MIT 不可撤回”，不制造错误预期；
5. 商业使用需单独授权，通过 GitHub issue 联系。

## 理由

- PolyForm Noncommercial 是为软件设计的非商业许可，定义比自定义“禁止商用”条款清晰；
- 它保留修改与分发权，配合附加许可可以满足“商业渠道免费分享”；
- 不采用“假装 MIT 但附加禁止商用声明”的做法：那会与 MIT 授权冲突，也不可执行；
- 不采用 AGPL/BSL：AGPL 允许商业使用，BSL 是延时开源，都不符合“非商业”意图；
- 单作者项目，版权集中，具备更改未来版本许可的条件。

## 后果

正面：

- 未来版本不再被商业产品默认使用；
- 免费分享、学习、教学、非商业研究不受影响；
- 许可边界、历史版本和商业授权路径都有明确文档。

负面：

- **不再是 OSI 开源项目**；GitHub 可能显示 “Other/View license”，部分发行版/镜像会拒绝；
- 已发布的 MIT 副本（包括 `429dcaf`）仍可被商业使用，无法撤回；
- 可能降低外部贡献意愿；
- 需要持续维护 `docs/legal/LICENSING.md` 与商业授权沟通。

## 替代方案

| 方案 | 放弃原因 |
|------|---------|
| 继续 MIT | 与“不允许商业使用”的意图冲突 |
| AGPL-3.0 | 仍是开源许可，允许商业使用；只是增加源码义务 |
| BSL 1.1 | 延时转为开源，限制的是“生产使用”，不是非商业 |
| Elastic License 2.0 | 只限制托管服务，内部商业使用仍允许 |
| 自定义“禁止商用”条款 | 定义模糊、可执行性差，容易与现有 MIT 冲突 |
| 撤回/重写历史 | 已公开的 MIT 授权无法撤回；强推历史会破坏引用与信任 |

## 重新评估条件

- 所有者决定回到 OSI 开源；
- 出现明确的商业授权需求，需要双许可或调整附加许可；
- 收到律师关于 PolyForm 条款适用的具体意见；
- 主要贡献者引入，需要贡献者许可协议（CLA）。
