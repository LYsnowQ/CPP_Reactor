## 为什么是 2.0.0

按 [SemVer](../conventions/VERSIONING.md)，本次包含三项不兼容变更：

1. `/query`、`/sql` 默认不注册，必须 `--enable-sql`；
2. `SQLConfig` 移除从未生效的字段，并启用启动校验；
3. 许可证从 MIT 改为 PolyForm Noncommercial 1.0.0（历史 MIT 保留）。

功能修复本身（安全、失败回写、静态拒绝名单）不足以单独构成 MAJOR，但叠加接口与许可变更后，
2.0.0 是诚实的版本号。
